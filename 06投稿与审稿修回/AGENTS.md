# 投稿与审稿修回

适用于投稿准备、匿名化、材料核对和审稿回复；与根目录规则共同使用。

## 1. 投稿准备

1. 核验目标期刊官方作者指南并记录日期；无法访问时说明缺口，不将旧要求或通用模板称为现行规定。
2. 按适用要求检查文章类型、篇幅、摘要、关键词、引文、表图、补充材料，以及数据/代码、伦理、利益冲突与作者贡献声明。
3. 核对摘要、正文、附录和投稿字段，文内引文与参考文献双向匹配；不虚构伦理编号、注册、作者贡献或数据可得性。
4. 双盲审稿检查正文、致谢、文件名、文件属性、仓库和补充材料中的身份线索，同时保留必要的方法与来源信息。

## 2. 审稿回复

1. 保留意见原文、审稿人编号与位置，拆成可回应事项；实际意见与自行提出的拓展建议分开。
2. 逐项决定接受、部分接受、澄清、补充证据或据理不同意，给出具体理由，不以迎合所有意见为目标。
3. 记录实际改动、依据、稿件位置和状态；完成修改或运行分析后才能声称已完成，计划事项明确标记。
4. 核对回复信、修订稿、表图和补充材料一致，不承诺不存在的改动，不虚构期刊政策或支持文献。

## 3. 交付与核验

按任务交付投稿核查结果，或“意见—回应—改动位置—状态”对照与回复信草稿。列出待作者确认的声明与关键判断；仅在明确授权后实际提交，不因准备材料而推定投稿权限。
