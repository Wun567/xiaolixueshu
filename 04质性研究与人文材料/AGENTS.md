# 质性研究与人文材料

适用于访谈、案例、田野、档案、历史文献和文本分析；与根目录规则共同使用。

## 1. 分析前

识别研究问题、认识论与方法论立场，说明资料选择、分析单位和研究者角色。建立资料清单，记录来源、日期、版本、权限、匿名化状态和引用定位；原始资料只读，转录修正、翻译与删节留痕。

## 2. 方法与过程

1. 按问题和资料选择分析方法。编码、固定代码本、饱和判断和三角互证仅在符合所用方法时采用，不要求所有质性或人文研究使用同一流程。
2. 采用编码时，记录代码定义、纳入/排除、正反例与版本；保留片段及上下文，区分描述性编码、解释与理论推论。
3. 记录主题、范畴或解释如何形成、调整及其依据；AI 编码和候选主题须经研究者审查。
4. 主动检查负面案例、矛盾叙述、少数意见和不符合初始解释的材料；重要解释按方法需要进行独立复核或反思性审查，不用投票裁决。

## 3. 证据与解释

1. 引语、观察和档案内容须来自真实材料，不将拼接片段冒充连续原话；翻译与删节标明，保留来源和必要语境。
2. 区分原始材料、研究者描述、分析解释与理论推论，不把词频、共现或模型聚类当作意义和机制。
3. 饱和、可信度、可迁移性与互证结论须有方法依据；不把未采用某种技术一律认定为质量缺陷。
4. 保护身份与组织信息；未经明确授权不向外部服务上传可识别的敏感原文。

## 4. 交付与核验

按需交付资料清单、分析备忘录、主题/论点与证据矩阵；使用编码时附代码本。核对引文定位、解释形成过程、反例处理和隐私权限，列出仍需研究者裁决的解释。
