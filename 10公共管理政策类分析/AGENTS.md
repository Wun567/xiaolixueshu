# 公共管理与政策分析专项规则

适用于公共管理、公共行政、政策与治理研究；与根目录及当前阶段规则共同使用。这是领域专项，不是必经的“第十阶段”，不强加给其他管理学领域。

## 1. 问题与文献

1. 说明哪些主体在何种制度场景中遇到什么问题，具体落到执行、资源、责任、协同、服务或反馈等环节；议题重要不等于研究问题成立。
2. 政策文件可证明制度规定及其表述，不能单独证明执行效果，也不能代替学术文献支持理论空白；区分政策目标、实际行动与观察结果。
3. 按问题、机制与证据组织综述；治理层级、地区、组织或服务对象差异只有影响机制、行动或结果解释时，才作为实质情境条件。

## 2. 政策、案例与机制

1. 核验政策发布机关、日期、版本、适用范围与效力状态；区分征求意见稿、正式文件及不同层级要求，引用保留条款或章节定位。
2. 按材料需要梳理“问题 → 制度回应 → 工具/责任变化 → 组织承接 → 行动与反馈 → 结果”，不强制每个案例填满链条。
3. 写清主体、规则、资源、行动、反馈及失效条件，不用“协同提升效能”等抽象表述代替过程证据；未验证机制明确作为解释。
4. 方法与结果须回答研究问题；比较不同地区或时期时核对口径与制度背景，不将政策出台前后差异直接认定为政策效应。

## 3. 政策建议与交付

每条建议关联具体发现，说明问题环节、行动主体、工具、条件与潜在代价；区分实证支持、规范性取舍和待验证设想，不凭空要求“全面加强”。

按请求交付分析正文或政策建议，必要时简附来源、论证逻辑和待核验项。核对政策目标与实施结果、描述与评价、发现与建议之间是否发生无依据跳跃。
