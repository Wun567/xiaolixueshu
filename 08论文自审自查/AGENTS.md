# 论文自审自查

适用于初稿或指定章节的建设性审查；与根目录规则共同使用。默认交付问题与修订建议，不擅自重写正文。

## 1. 审查范围

读取实际可用稿件、研究问题、理论、方法、结果及目标规范，说明审查范围。缺少上下文先核实，不能把未见材料视为研究缺陷；不凑问题数量，不预测或保证录用。

## 2. 核心检查

- 问题与综述：问题是否可研究，综述是否综合证据，空白是否具体且有依据。
- 概念与理论：定义、层级和机制是否清楚，竞争解释是否影响当前主张。
- 设计与证据：方法能否回答问题，主要判断是否有可定位依据，识别或解释边界是否成立。
- 结果与贡献：是否回应问题，区分发现与解释，贡献及实践建议是否与证据相称。
- 结构与一致性：段落是否推进，结尾是否形成判断，标题、摘要、正文、表图、附录及术语是否一致。
- 表达：检查空泛评述、抽象词堆叠及冗余限定；保留有实质作用的条件，不把风格偏好当作学术缺陷。

## 3. 问题分级

| 级别 | 判定依据 |
| --- | --- |
| P0 必须修复 | 已核实的重大事实错误、虚假引用、伦理/隐私风险、结果与输出不符或核心方法失效 |
| P1 重大问题 | 问题不清、论证断裂、关键证据不足、设计无法回答问题或贡献超出证据 |
| P2 重要改进 | 结构、概念解释、方法报告或讨论影响理解 |
| P3 编辑建议 | 冗余、措辞、格式和术语一致性 |

严重程度与核实状态分开：疑点标为待核实，不因风险可能严重就当作已证实错误。每项意见定位原句、段落或表图，说明依据、影响与最小修订办法；纯偏好单列。

## 4. 交付与核验

交付简明审查结论和按优先级排列的修订计划，可合并为一份报告；另列重要待核验项与作者决策。复核意见是否超出实际阅读范围、重复或引入无关防御目标；授权改稿时仅传递筛选后的修改目标。
