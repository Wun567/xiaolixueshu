# 文献综述与精读

适用于检索、单篇精读和跨文献综合；与根目录规则共同使用，按任务选择流程。

## 1. 输入与证据

1. 读取研究问题、构念定义、已有笔记与可访问文献，识别重复文件、缺页和解析问题；问题尚不明确时可先做标为探索性的梳理。
2. 每篇标注题录、摘要、部分全文、全文或全文及附录的实际阅读范围；元数据核验状态单列，不能用“待核验”替代阅读深度。
3. 关键发现与引语保留页码、章节或表图定位；无法读到的附录、图表和扫描页须说明，疑似解析错误回看原页，不擅自修正数字。
4. 检索保留平台、日期、检索式和筛选范围；系统性综述另存筛选、排除与去重记录，不能把定向检索称为穷尽检索。

## 2. 单篇精读

按任务提取以下信息，不强制为每篇填满所有字段：

- 书目信息、稳定链接、阅读范围与核验状态。
- 研究问题、理论视角、构念定义及分析层级。
- 情境、样本/资料、方法、机制与边界。
- 主要发现及其证据定位；作者自述贡献与局限。
- 对当前课题的支持、挑战或补充，以及待核验事项。

原作者发现、原作者解释与 Agent 评价分开记录。中英文构念按定义、理论位置、测量与情境比较，不能仅凭译名判断是否相同；必要时建立术语对照。

## 3. 跨文献综合与写作

1. 围绕研究问题的推进组织：已有解释、理论转向、证据分歧与未解决问题。作者姓名用于归属，不代替综合。
2. 比较构念、机制、层级、情境和方法；区分真实冲突与设计或测量差异，保留反例及证据边界。
3. 核心判断须有具体研究内容支持，不凑文献数量；证据不足时补检索或缩小主张。
4. 研究空白须核查相邻概念、术语和学科，具体说明未解释的机制、条件、矛盾或层级联系及其重要性。
5. 述评结尾交代已有证据、争议、候选问题和待补材料；除任务需要，不提前展开本研究模型、样本或问卷设计。

## 4. 交付与核验

按需交付精读笔记、比较矩阵或综合正文，可沿用 `notes/`、`matrices/`、`outputs/` 等既有目录，不强制拆成多个文件。

提交前核对阅读范围、关键引文定位、作者观点与自身推断、跨文献关系及空白依据；将待核验事项和研究者决策项简短列出。
