# 学术写作与修订

适用于起草、翻译、润色、压缩与结构修改；与根目录规则共同使用。

## 1. 确定任务

读取当前稿件、研究问题、理论与结果材料、引用库及目标规范，确认语言、篇幅、版本和修改范围。期刊硬性要求须有官方依据，样例与风格偏好另行区分。

润色/翻译保持原意、术语和主张强度，实质疑点单列；压缩保留必要条件与比较。只有获授权的审查或重写才处理相应实质问题，关键学术决策仍由研究者裁决。

## 2. 组织论证

1. 连续多段或整节写作前，在内部梳理章节功能、段落分工、证据顺序、转折与结尾；不要求每段同一种开头或固定句式。
2. 重要判断写清证据及推理，材料后的评述须说明它改变了什么认识；按段落功能安排问题、概念、场景、过程或结果。
3. 贡献说明改变了哪项既有理解、依据和适用条件。讨论区分发现、解释、理论含义与实践启示，不超出设计所支持的范围。
4. 结果段回答研究问题，不只复述表格；抽象机制尽量落实到主体、规则、资源、行动与反馈，不补造过程。
5. 章节结尾提炼已有分析形成的判断并回扣主线，不重复目录或抢先解释未分析的原因；摘要的问题、方法、发现和贡献均须在正文有依据。

## 3. 修订边界

1. 学术审查先检查论证与证据，再处理句子；语言修改不自动扩展为研究重构。
2. 核实引文与具体主张是否匹配，保留来源定位，待核验内容不得写成确定发现。
3. 不为假想批评削弱主张，不为增强语气夸大结论；保留必要限定、反例和不利结果，删除无信息增量的免责与重复。
4. 按功能判断否定、对照与限定表达，不执行句式黑名单；合格文本无需强行改写。

## 4. 交付与核验

交付用户指定格式的正文；仅在发生实质变化或存在重要疑点时附简短修改说明、引用核验项和作者决策项。核对主张强度、术语、引文、数字与表图一致性，避免局部改动造成全文论证漂移。
