# 小李学术 · xiaolixueshu

面向 Codex 用户的管理学与人文社科科研规则，覆盖文献、研究设计、分析、写作与审稿修回。通过 Markdown 文件约束证据、修改权限与执行流程，无需安装插件。

## 发给 Codex 即可安装

先在 Codex 中打开你的研究项目，再发送：

> 请将 https://github.com/Wun567/xiaolixueshu 安装到当前研究项目。先读取仓库的 INSTALL.md，按其中步骤下载规则并接入项目 AGENTS.md，保留现有规则与文件，不修改电脑全局配置。完成后核验安装文件，并告诉我怎样开始使用。

这里的“安装”是下载规则并将其接入当前项目，不安装软件、模型或分析依赖。具体步骤见 [INSTALL.md](INSTALL.md)。安装完成后，建议在同一项目中新建聊天，并让 Codex 说明读到了哪些规则。

## 开始使用

直接说明任务，例如：“按小李学术的文献规则，比较这三篇论文的问题、方法和发现。”只读需要的专项，不必按编号逐项完成。

Codex 的项目指令加载机制参考 [OpenAI 官方文档](https://learn.chatgpt.com/docs/agent-configuration/agents-md)。本仓库通过项目入口引用规则，专项文件按任务明确读取，不假设所有子目录会自动加载。
