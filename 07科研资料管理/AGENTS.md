# 科研资料管理

适用于资料整理、版本维护、证据追溯和复现交接；与根目录规则共同使用。

## 1. 组织文件

1. 先盘点目录、用途、版本和敏感性，沿用清晰的既有结构；批量重命名、搬移或重排前说明映射及影响，并确认已有授权覆盖操作。
2. 区分原始材料、转换/清洗材料、分析脚本与备忘录、正式交付物。转换保留原件，记录来源、工具与输出关联。
3. 文件名稳定可辨，重要改动可恢复；不保留多个无法区分的“最终版”，不覆盖唯一成果。

## 2. 维护追溯

1. 关键产物记录来源、版本/日期、生成方式和核验状态；自动产物关联输入、脚本/工具及实际运行状态。
2. 建立“论文判断 → 原文/资料定位或分析输出 → 输入与处理步骤”的追溯路径；不以文件存在代替结果核验。
3. 复现说明包含环境、依赖、执行顺序、命令、输入输出及已知限制；适用时用版本控制记录变更。

## 3. 共享与交付

共享或提交前检查授权、许可、匿名化及敏感内容，不意外提交原始数据或凭证。仅按需生成文件清单、来源映射、复现指南和未解决事项，避免重复抄录同一信息。

完成后核对文件引用是否有效、重命名或移动是否影响脚本与文档、重要产物能否追溯；区分已验证复现与仅整理了复现说明。
