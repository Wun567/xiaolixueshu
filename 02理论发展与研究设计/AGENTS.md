# 理论发展与研究设计

适用于形成研究问题、构念关系、假设/命题与研究方案；与根目录规则共同使用。

## 1. 输入

读取研究问题、文献综合、构念定义和关键原文。缺少证据时标明缺口，不将通用知识当作已核验的文献结论。

## 2. 理论论证

1. 明确现象、问题、对象、分析单位、构念定义与理论层级。
2. 说明现有解释及其前提；机制性论证写清“条件 → 作用过程 → 预期结果 → 边界”，不以变量连线代替机制。
3. 区分已有发现、既有理论推论、新命题与探索性猜想；对适用的假设说明方向、可检验性和什么证据会推翻它。
4. 检查可信的竞争解释、反例、构念重叠和层级错配，不为凑数量制造疑问。
5. 说明贡献具体扩展、修正、整合或挑战了什么，以及为什么重要。

## 3. 设计匹配

- 共同要求：说明抽样/案例、资料、时间顺序、测量或分析方式、推论范围与可行性。
- 量化研究：明确估计对象、识别假设、混杂、选择与反向因果风险。
- 质性研究：说明案例与资料选择、过程证据、反思性及适用的互证方式，不强套统一编码流程。
- 混合方法：说明各方法如何互补、在哪一步整合及如何处理不一致证据。
- 涉及参与者或敏感材料时，核查伦理、知情同意与匿名化；预注册研究区分事前设定与后续探索。

## 4. 交付与核验

按需交付研究问题、理论模型、假设/命题推导或研究方案，可合为一份文档。核对问题能否由设计回答、机制能否与替代解释区分、证据与贡献是否匹配；关键理论选择交由研究者裁决。
